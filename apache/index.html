01 · Architecture

The Self-Healing Architecture

Watch the signal travel through the entire self-healing system topology, from detection to notification.

01 · Network
VPC Subnet, route table and security group provide the EC2 network boundary.
02 · Workload
EC2 Amazon Linux workload with HTTPD, CloudWatch Agent and SSM Agent.
03 · Monitor
CloudWatch P1 procstat metric and P2 CPUUtilization alarm evaluation.
04 · Controller
Lambda Parses alarmData, gates actionable alarms and controls remediation.
05A · P1

SSM — EC2 → HTTPD

Restart httpd, verify service state, retry once if required, then perform the 15-second stability check.

05B · P2

Lambda diagnostics

Collect CPU-oriented diagnostic information. The P2 path is intentionally diagnostic-only and does not restart the server.

06 · NOTIFICATION
SNS → Email notification Lambda publishes the incident outcome so the operator receives detected, resolved, or escalated status.

03 · Execution

End-to-end P1 execution

Detection, controlled action, verification and honest escalation.

01 · DETECT

Alarm becomes actionable

CloudWatch evaluates the P1 procstat metric and sends the direct alarm event to Lambda.

02 · DECIDE

Lambda validates

Lambda parses alarm payload, applies actionable-alarm gating and maps the alarm to P1.

03 · REMEDIATE

SSM executes

SSM runs the HTTPD restart command on the managed EC2 instance with immediate verification.

04 · PROVE

Stability + notification

Lambda verifies stability before SNS reports the final result to subscriber topics.
